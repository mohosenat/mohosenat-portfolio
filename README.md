# Mohosenat Jahan — Premium Portfolio

A responsive portfolio starter built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lucide icons, and `next-themes`.

## Features
- Premium black + purple/pink gradient design
- Light theme using `#FFFFFF` and `#F0F0F3`
- Responsive navigation and mobile menu
- Theme toggle
- Hero, Skills, About, Projects, Education, Contact sections (Skills comes before About)
- Entrance and hover animations
- Custom `loading.tsx` and `not-found.tsx`
- SEO metadata and semantic markup

## Run locally
1. Install Node.js (LTS) if you haven't already.
2. Open this folder in VS Code.
3. Open the terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open `http://localhost:3000`.
